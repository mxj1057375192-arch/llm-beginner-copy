## 二、S1 消融：head 数 / 层数

固定 d_model=128，只改 head 数或层数（每组 5 轮）：

| 配置 | 参数量 | dev 准确率 | 相对 baseline |
|---|---|---|---|
| n_layers=1, n_heads=4 | 0.69 M | 0.8958 | −0.6 pt |
| n_layers=2, n_heads=4 | 0.89 M | 0.8950 | −0.7 pt |
| **n_layers=4, n_heads=4（baseline）** | 1.29 M | **0.9017** | — |
| n_layers=4, n_heads=1 | 1.29 M | 0.8858 | −1.6 pt |
| n_layers=4, n_heads=8 | 1.29 M | 0.8958 | −0.6 pt |

（另有一组 d_model=64, n_heads=2, n_layers=2，0.35 M 参数，dev 0.8508，与 baseline 差距 −5.1 pt，说明**宽度比深度更值钱**。）

三条观察：

1. **层数收益很快饱和**。1 层就有 0.8958，4 层只多 0.6 个点。这个任务只需要判断
   情感极性，不需要深层组合语义，所以浅模型就够。代价是参数量从 0.69 M 涨到 1.29 M，
   收益/成本比很差。
2. **单头明显更差**（0.8858，−1.6 pt），说明多头确实在做不同的事。
   但 8 头并没有比 4 头好（0.8958），多头收益在 4 头附近饱和 —— 再切细只会让
   每个头只有 16 维，表达力反而下降。
3. **宽度比深度敏感**：把 d_model 从 128 砍到 64（同层数附近对比）掉 5 个点，
   比砍层数掉得多。

## 三、S2 消融：去掉 residual / LayerNorm

| 配置 | dev 准确率 | 现象 |
|---|---|---|
| baseline（都有） | **0.9017** | 正常收敛 |
| `--no-residual` | **0.8508** | 能训，但 4 轮只到 85，train acc 0.8768 —— **明显欠拟合** |
| `--no-layernorm` | 0.8875 | 还能收敛，但更抖、更慢（最佳出现在第 2 轮后被超过）|

去掉残差后的训练轨迹：

```
[3/4] train loss 0.4334 acc 0.8370 | dev loss 0.4279 acc 0.8367
[4/4] train loss 0.3398 acc 0.8768 | dev loss 0.3977 acc 0.8508
```

train loss 一直是 baseline 的两倍左右，说明**不是过拟合，而是信息传不下去**：
4 层网络没有残差这条「高速公路」，梯度在回传时逐层衰减。
这正好反过来印证了 `src/block.py` 里写的那句话 —— 残差是深层网络能训起来的前提。

LayerNorm 的影响小一些：本任务网络只有 4 层、batch 也够大，没有它仍能收敛，
但它让训练更稳。在更深的模型上它的重要性会迅速上升。

## 四、注意力可视化：模型到底在看什么

### 4.1 三种样本的热图

`figures/attn_positive.png` / `attn_negative.png` / `attn_long.png`（最后一层，多头平均）。
按「每一列被所有 query 关注的权重之和」排序，被关注最多的词元是：

| 样本 | Top-5 被关注词元 |
|---|---|
| 正面「…服務態度亦算不錯,但房間空間太小…」 | **不**(1.14) **不**(1.13) **不**(1.13) 空(1.06) 可(1.05) |
| 负面「商品的不足暂时还没发现…」 | 还(1.63) 速(1.60) .(1.11)×3 |
| 长句「…被告知要出示结婚证…」 | 晚(1.12) **婚**(1.08) 有(1.07) **证**(1.07) |

正面样本里 **「不」「可」** 排在最前，而句中真正的情感判断点恰恰是「**不错**」这个搭配
（还有「但…太小」这个转折）—— 这需要「不 + 可」和「不 + 太」两组 token 联合表示，
模型把注意力放在这两个字上，方向是对的。
长句样本里 **「婚」「证」** 被突出，对应句子里的冲突点（要求出示结婚证），
也符合直觉。

### 4.2 但必须说清：这里的注意力非常「平坦」

`figures/attn_entropy.png` 是本次实验最有信息量的一张图。
对最后一层、60 个词元的样本，逐行算注意力分布的熵：

| 层 | 平均熵 (nat) | 占均匀上界 ln(60)=4.094 的比例 | 最大权重（均匀应为 0.0167）|
|---|---|---|---|
| 第 1 层 | 4.043 | 98.8% | 0.1504 |
| 第 2 层 | 4.065 | 99.3% | 0.0310 |
| 第 3 层 | 4.092 | 99.9% | 0.0200 |
| 第 4 层 | 4.092 | 99.9% | 0.0212 |

**结论要说白：注意力几乎就是均匀分布。** 一行的熵接近理论上界，
意味着「这个位置把注意力差不多平均撒给了所有词」，而不是「盯着某个关键词」。
所以：

1. **热图看起来一片平色不是画错了**，是模型确实没学出稀疏的词元对齐。
   单看某一个 head 也一样（`figures/attn_heads.png` 四个 head 都是平色）。
2. **「模型在看『不错』『失望』」这类解读在本实验里不成立。**
   4.1 里 Top-5 的相对排序有一点信号（「不」「婚」「证」确实排前面），
   但绝对权重只比均匀值高百分之几十，不足以构成解释。
3. 有意思的是**层间趋势**：第 1 层还有一点结构（最大权重 0.15，熵 98.8%），
   越往深层越均匀。结合 residual 会发现原因：`x = x + Attn(...)` 是累加的，
   即使某个头的注意力很平，深层的表示也已经被前面几层加工过了；
   分类头用的是 mean pooling，**均值本身就不在乎注意力是否稀疏** ——
   均匀注意力 + mean pooling ≈ 对表示做一次平均，对情感分类这种
   「关键词袋」式的任务已经够用。

换句话说：**这个任务不需要稀疏注意力也能拿到 0.90**。这解释了为什么
层数/头数消融的收益那么小 —— 模型根本没把注意力当作主要的判别工具，
判别力主要来自 token embedding 与逐位置 FFN。

## 五、M4：causal mask 与 toy 语言模型

`toy_lm.py` 复用与分类器同一套 attention / block 代码，只把 mask 换成上三角，
在仓库自带唐诗语料（15755 字）上做字符级 next-token 预测（600 步）：

```
[因果性验证] 改动最后 5 个词元后：
    过去 19 个位置的输出最大变化 = 0.000e+00   <- 没泄漏
    被改动位置的输出最大变化       = 7.271e+00   <- 确实用了上下文
```

两行都要看：第一行为 0 说明未来信息没泄漏；第二行明显大于 0 说明
mask 没有把整个注意力矩阵都堵死（否则输出会退化成常数，两行都是 0）。

训练 600 步后 loss 5.48（ppl 240），生成结果不成句：

```
春眠不觉晓 -> 春眠不觉。皇人秋，人即吞，金骨。。矫吞忧。东不领。紫为将烟始竹雨自取…
```

这个结果符合预期：15755 个字的语料、1.12 M 参数、600 步，只够模型学会
「输出看起来像汉字、偶尔押韵」的程度。它证明的是**因果语言模型这条流水线是通的**，
不是生成质量 —— 生成质量是任务二（mini-GPT）要解决的问题。

## 七、结论

1. **M1–M5 全部达成**：手写 attention 数值正确（1.19e-07）、多头 + encoder block 形状正确、
   分类 dev **0.9017**（> 0.80，也超过 0.85 参考基线）、causal mask 无泄漏、产出 6 张图。
2. **最重要的实验结论不是准确率，而是「注意力可以是平的」**：
   熵分析显示 99% 的注意力熵水平说明模型在做近似平均池化，
   而它照样拿到 0.90。这提醒我：注意力权重只能当**线索**，不能当**解释**；
   要证明「模型看了哪个词」，需要消融或梯度类归因，而不是盯着热图。
3. **消融结果与理论一致**：残差是深层可训练的前提（去掉掉 5 个点），
   多头优于单头（+1.6 点）但很快饱和，宽度比深度更敏感。
4. **可复现**：`dsh-scripts\run_experiments.ps1` 一键重跑全部 9 组配置并追加到
   `figures/experiments.json`；`dsh-scripts\finalize_task1.ps1` 一键出图 + 自检。
